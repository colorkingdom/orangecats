# Red and non-red frequency in cats

A small interactive calculator based on the equations in the accompanying spreadsheet.

## Publish with GitHub Pages

1. Add `index.html` to the root of the GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then choose the `main` branch and `/ (root)` folder. Save.
4. GitHub will show the published site address in the Pages settings once it is ready.

To update the calculator later, edit `index.html` and save the change to the repository. GitHub Pages will publish the updated page.
